CatBoost 피처 전처리 요약표 (구글 독스용)

현재 최종 모델(train_cat_single.py)에 적용되어 있는 피처 전처리 방식을 4가지 그룹으로 나누어 정리한 표입니다.

==================================================
1. 수식 기반 파생 변수 (Derived Features)
==================================================

[피처명] same_hand
- 설명: 투타 매치업 (동일 손 여부)
- 전처리 방식: pitcher_hand == batter_hand (True=1, False=0)

[피처명] count_advantage
- 설명: 볼카운트 투수 유리도
- 전처리 방식: (strikes_before - balls_before + 3) / 5.0

[피처명] win_expectancy_pitcher_team
- 설명: 투수 팀 기준 기대 승률 압박감
- 전처리 방식: top_bottom이 'T'(초)이면 home_win_expectancy, 아니면 away_win_expectancy를 가져온 뒤, 50을 기준으로 절대값 거리를 구함 ((x - 50).abs() / 50.0)

[피처명] re24
- 설명: 아웃 및 주자 상황별 기대 득점
- 전처리 방식: (1루, 2루, 3루, 아웃카운트) 상태 코드를 고정 RE24 테이블(24개 상태)에 매핑하여 연속형 변수로 취급

[피처명] pitcher_momentum_1_vs_5
- 설명: 제구 성공률 단기 모멘텀
- 전처리 방식: 직전 1경기 성공률 - 직전 5경기 성공률.fillna(0)

[피처명] pitcher_condition_vs_baseline
- 설명: 제구 성공률 컨디션
- 전처리 방식: 직전 3경기 성공률 - 누적 성공률

* 제거됨: pitcher_middle_momentum_1_vs_5, pitcher_middle_condition_vs_baseline (실투율 모멘텀 관련 피처 제외됨)


==================================================
2. 수치형 스케일링 변수 (Scaled Numeric Features)
==================================================
참고: 트리 모델(CatBoost)에서는 이러한 선형 스케일링이 성능에 큰 영향을 주지는 않지만, 다른 딥러닝/선형 모델과의 호환성 유지를 위해 스케일링된 채로 사용하고 있습니다.

[피처명] balls_before
- 원본 설명: 볼 카운트
- 전처리 방식: / 3.0

[피처명] strikes_before
- 원본 설명: 스트라이크 카운트
- 전처리 방식: / 2.0

[피처명] inning
- 원본 설명: 이닝
- 전처리 방식: (inning - 1).clip(upper=8) / 8.0

[피처명] li
- 원본 설명: 상황 중요도
- 전처리 방식: .clip(upper=2) / 2.0

[피처명] asof_pitcher_n
- 원본 설명: 투수 누적 투구수
- 전처리 방식: np.log1p() (로그 변환)

[피처명] asof_pitcher_pitchmix_n
- 원본 설명: 투수 구종 표본 수
- 전처리 방식: np.log1p() (로그 변환)

* 제거됨: outs_before (base_out_state와 re24로 통합), score_diff_pitcher_team, asof_batter_n (모델 간소화를 위해 사용 제외)


==================================================
3. 원본 유지 수치형 변수 (Raw Numeric Features)
==================================================

[카테고리] 시간 변수
- 포함 피처명: season, game_month
- 비고: 그대로 사용 (이전의 주기 변환 삭제됨)

[카테고리] 비율(Rate) 변수
- 포함 피처명: asof_pitcher_success_rate, asof_pitcher_strike_rate, asof_pitcher_breaking_rate, asof_pitcher_offspeed_rate, asof_pitcher_reverse_rate, asof_pitcher_ball_rate, asof_pitcher_fastball_rate
- 비고: 전처리 없이 원본 사용

[카테고리] 과거 이력(Rate) 변수
- 포함 피처명: asof_batter_success_rate, asof_pitcher_prev1_game_success_rate, asof_pitcher_prev3_game_success_rate, asof_pitcher_prev5_game_success_rate
- 비고: 전처리 없이 원본 사용 (결측치는 CatBoost가 자체적으로 처리)

* 제거됨: 주자 개별 변수(runner_on_1b, runner_on_2b, runner_on_3b), asof_pitcher_middle_rate 및 모든 middle_rate 계열 과거 이력 변수


==================================================
4. 범주형 변수 (Categorical Features)
==================================================
참고: 해당 변수들은 cat_cols 리스트에 포함되어 CatBoost의 cat_features로 입력되며, 모델 내부적으로 강력한 교호작용(Combination)을 파악하는 핵심 피처들입니다. 결측치는 일괄적으로 'MISSING' 문자열로 대체됩니다.

[피처명] pitcher_team_id
- 설명: 투수 소속 팀 ID

[피처명] batter_team_id
- 설명: 타자 소속 팀 ID

[피처명] pitcher_hand
- 설명: 투수 투구 손

[피처명] batter_hand
- 설명: 타자 타격 손

[피처명] game_type
- 설명: 경기 유형

[피처명] base_out_state
- 설명: 24가지 주자/아웃 상황 (주자와 아웃카운트 조합을 하나의 문자열로 결합)

* 제거됨: pitcher_id, batter_id (과적합 우려로 제외됨), top_bottom (피처 중요도가 0으로 나와 제외됨)
